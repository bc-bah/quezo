# Assessment

Quezo supports authors creating quizzes and learners completing them.
The initial context is low-stakes assessment within one organization.

## Language

**Question**:
A reusable assessment item with its own identity, independent of the quizzes
that include it.
_Avoid_: Quiz question when referring to the reusable item.

**Question version**:
A fixed revision of a question's wording, answer options, correct answer,
default points, and explanatory feedback.

**Question bank**:
An author's organized collection of reusable questions.
_Avoid_: Pool, which implies selecting a subset for delivery.

**Quiz**:
An assessment definition that an author prepares and publishes.
_Avoid_: Attempt, assignment, exam when referring to the reusable definition.

**Quiz version**:
A fixed published composition of question versions and assessment rules.

**Assignment**:
An authorization for a named learner to take a published quiz.
_Avoid_: Quiz when referring to distribution or eligibility.

**Attempt**:
One learner's execution of an assigned quiz.
_Avoid_: Submission when referring to work still in progress.

**Attempt question**:
The question content, option order, and scoring definition selected for one
particular attempt.

**Response**:
A learner's answer to an attempt question, including an explicitly cleared answer.

**Finalization**:
The irreversible end of an attempt's editable period, through submission or
expiration.

**Grade**:
The scoring outcome for a finalized attempt, distinguishing unanswered from
incorrect responses.

**Result policy**:
The rules determining when a learner may see their score, correct answers,
and explanatory feedback.
